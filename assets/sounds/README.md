# assets/sounds/

Здесь лежат opus-файлы звуков движка (не сценария) — для UI: меню, настроек,
навигации.

## Файлы

| Файл                       | Назначение                                                |
|----------------------------|-----------------------------------------------------------|
| `main_menu_ambient.opus`   | Фоновый эмбиент главного меню. Зацикленный. Играет всё время, пока игрок в меню выбора сценария или в подменю настроек. Останавливается при входе в сценарий и при выходе из игры. |
| `main_menu_choice.opus`    | Одноразовый UI-клик. Играет один раз при нажатии Enter в меню (выбор сценария, вход в настройки, выбор пункта настроек). На бэкенде `opusdec+winsound` НЕ проигрывается, чтобы не останавливать эмбиент (winsound однопоточный). На `ffplay` проигрывается параллельно с эмбиентом. |

## Формат

- Только `.opus`. Ogg Opus (`.ogg`) тоже принимается.
- ASCII-имена, без пробелов.
- `main_menu_ambient.opus` — зацикленная петля 30–120 секунд. Bitrate 48–64 kbps.
- `main_menu_choice.opus` — короткий звук 0.05–0.5 секунды (клик). Bitrate 64–96 kbps.

## Где взять / как сделать

- Сгенерировать через любой opus-кодер (например, `opusenc` из opus-tools):
  ```
  opusenc --bitrate 48 input.wav main_menu_ambient.opus
  ```
- Скачать с бесплатных библиотек звуков (freesound.org, opengameart.org) и
  перекодировать в opus.

## Что если файлов нет

`boot.py` при запуске проверяет наличие этих файлов и предупреждает, если их
нет. Движок продолжает работать, просто меню будет без звука.

## Поиск файлов в коде

Движок ищет файлы через `storage.get_asset_sound_path(name)`:

```python
storage.get_asset_sound_path("main_menu_ambient")
# → /путь/к/игре/assets/sounds/main_menu_ambient.opus
# или None, если файла нет
```

В `main.py` пути кешируются при первом обращении:

```python
_play_menu_ambient()      # запускает фоновый эмбиент
_play_menu_choice()       # проигрывает UI-клик (только на ffplay-бэкенде)
```
